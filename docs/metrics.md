# Success Metrics

The first version should be judged by operational outcomes, not agent spectacle.

## Product Metrics

| Metric | Description |
|---|---|
| Time to first credible hypothesis | From initial question to a plausible diagnosis candidate |
| Time to assembled incident context | From incident start to a consolidated evidence view |
| Repeat investigation token cost | Token usage for the same investigation type over multiple sessions |
| Memory reuse rate | Number of durable memory items surfaced per investigation |
| Sessions resolved without manual context rebuilding | Percentage of sessions where the system's prior knowledge was sufficient |

## Business Metrics

| Metric | Description |
|---|---|
| Pilot-to-paid conversion | How many pilots convert to paid customers |
| MTTR reduction | Reduction in mean time to resolution for pilot teams |
| Escalation reduction | Fewer incidents requiring senior escalation |
| Weekly active engineers | Engineers using both CLI and UI at least once per week |
| Investigation recipe adoption | Number of saved recipes adopted and reused by a team |
